      几何 · 流动 · 气体

      kLa 随转速变化

      三条线为微泡通气量的 0.5×、1×、2×（大泡通气不变）；虚线为峰值细胞密度下的需求 kLa；圆点为当前工况。

      供氧能力与细胞密度

      斜线为耗氧 OUR；水平线为当前 kLa 下微泡气不同 O₂ 分数的最大 OTR。交点是可支撑的最高活细胞密度。

      pCO₂ 与大泡通气量

      峰值 VCD 下的稳态 pCO₂。绿色带为 40–120 mmHg 目标区间，红虚线为 150 mmHg。

      各级叶轮功率与能耗

      每级未通气功率与局部最大能量耗散率估算（ε_max = φ·Pg/V）。虚线为糖基化开始偏移的 6×10⁴ W/m³。

      转速 × 微泡通气量设计空间

      每个格子是一组（转速, 微泡 vvm）。绿色：供氧满足且全部判据通过，颜色越深 kLa 越高；黄色：供氧满足但有判据不满足（混合时间、Re、间距、淹没不计入）；红色：供氧不足。白点为当前工况。大泡通气量、O₂ 分数、细胞参数取左侧当前值。

          大型不锈钢罐与 big pharma 经验

          • Lonza 和 Genentech 已安装 20 m³ 级不锈钢细胞培养罐；商业工况平均能耗多在 10–20 W/m³，细胞在平均能耗高至 250 W/m³ 时仍生长到相同密度（Nienow）。
          • Roche 12,500 L 级三级叶轮罐的研究表明，在细胞培养通气条件下，因通气后液体有效密度下降，功率损失可达 50%（Sieblist 博士论文）。
          • BMS 在 5,000 L 与 25,000 L 罐上建立了 CO₂ 去除模型：去除速率取决于通气量、气泡停留时间和气泡被 CO₂ 饱和所需的时间，而不是 CO₂ 的 kLa。
          • Genentech（Mostafa & Gu 2003）：中试规模 dCO₂ 达 179 mmHg，比表达下降 40%；通过提高通气等手段把 dCO₂ 控制在 40–120 mmHg，比表达提高 41%。
          • 12,000 L 罐中钻孔分布器的出口气速高达 170 m/s，导致放大性能变差；更换孔更多、孔径更大的分布器后恢复。文献认为接近或超过 30 m/s 即对剪切敏感的细胞有害。
          • CHO 糖基化在能量耗散率 ≥ 6×10⁴ W/m³ 时开始偏移，比细胞破碎（LDH 释放）阈值低两个数量级。

                行业做法与本模型的位置

                • 勃林格殷格翰与汉堡工业大学用 M-Star（Lattice-Boltzmann 大涡模拟）做生物反应器设备表征，并以实验验证；其波浪式反应器 kLa 研究用 Higbie 渗透理论、以 Kolmogorov 尺度定义接触时间——本模型的局部 kL 采用同一思路。M-Star · Frontiers 2025
                • Thermo Fisher HyPerforma S.U.B. 100/500 L 的灌流放大用 LB-LES 评估混合效率；Cytiva Xcellerex XDR-10 有 Euler–Euler / Euler–Lagrange（OpenFOAM）的 kLa、混合时间、涡与剪切表征；Sartorius 用 CFD 证明 Flexsafe Pro 混合袋无持久死区。Frontiers 2023 · MHMT 2020 · Sartorius
                • DECHEMA 一次性技术专家组（2016）把流型、速度分布、功率、混合时间、停留时间分布、kLa 与能量耗散率列为可由 CFD 确定的参数。DECHEMA
                • 细胞阈值：CHO 在 EDR ≥ 6×10⁴ W/m³ 时出现糖基化偏移（Godoy-Silva 2009）；研究株在 2.9×10⁵ W/m³ 停止生长；单次暴露的致死范围约 10⁶–10⁸ W/m³（Chalmers 课题组）。Biotechnol Bioeng · Sci Rep 2017
                • 叶轮区峰值：ε_max/(N³D²) 约 Rushton 7–11、45° 斜叶 ≈2.4、推进式 1.1–1.8（LDA/PIV 测量汇总）。Chem Eng Sci 2014

                本模型的边界

                • 是过轴纵截面的二维降阶 CFD（D2Q9 TRT 格子 Boltzmann）：叶轮用体积力表示，湍流用混合长 ℓ = 0.07·D 闭合；速度由叶轮推力换算，用一个全局常数 C_T = 2.2 标定（六种预设的混合时间与关联式之比几何平均 ≈ 0.85）。体积统计按以罐轴为中心的圆环加权。不解析叶片尾涡、切向旋流与液面漩涡，叶轮区峰值 EDR 以文献系数补足。
                • 偏心、斜插与底装磁力搅拌（XDR、S.U.B.）是强三维流动，本模型按等效中心安装求解（偏心的作用近似为挡板），宜作方案间相对比较；3D 剖面贴图同样显示等效中心流场。
                • 气泡羽流以浮力（ρ·g·气体体积）驱动液相，与叶轮推力按物理比值叠加；气泡轨迹为单向耦合，含 Hinze 破碎、不含聚并。局部 kLa、混合时间与关联式差异在 0.3–2 倍内属正常量级。
                • 用于方案筛选、场地转移风险识别和指导实验；GMP 申报或设备选型定案前，应以三维 CFD（M-Star、Fluent、OpenFOAM）或实测混合时间、kLa 验证。

                  CFD 降阶模型（“CFD 流场仿真”页）

                  1. 流场：过轴纵截面 D2Q9 格子 Boltzmann，TRT 碰撞（Λ = 3/16），Guo 体积力；叶轮为作动盘体积力（按叶轮类型给排出角），气泡羽流按浮力 ρ·g·V_gas 与叶轮推力的物理比值叠加。湍流闭合为混合长
                    ν_t = ℓ²|S|，ℓ = 0.07·D
                    粗网格先算到准稳态再插值到细网格并做时间平均；中心安装时做轴线镜像平均。
                  2. 速度标定：叶轮推力 T = (4/π)·ρ·Nq²·N²·D⁴（径流 5/π），格子力换算 a = a_lat·s_u²/dx，
                    s_u = C_T·√(T·dx / (ρ·Σa_lat·dV))，C_T = 2.2
                    C_T 全局唯一，由六种预设的混合时间与关联式比较标定。标定常数
                  3. 能量耗散：ε 场形状取 2ν_t|S|²，按 Σε·ρ·dV = Pg + P_gas 归一；叶轮区峰值取网格峰值与文献 ε_max = C·N³D² 的较大者（C：Rushton 9、斜叶 2.4、推进式 1.5）。Kolmogorov η = (ν³/ε)^¼。
                  4. 混合：示踪剂在平均流场上做有限体积输运（TVD van Leer），湍流扩散 D_t = ν_t/0.7；t95 为三个探头全部进入并保持 ±5% 的时间。
                  5. 气泡与 kLa：拉格朗日气泡 = 液相速度 + 终端速度（Schiller–Naumann，上限 Mendelson）+ 湍流随机游走；局部 ε 超过 Hinze 判据 d_max = 0.725(σ/ρ)^0.6 ε^−0.4 时破碎。初始粒径默认按 Tate 式 d = (6 d₀ σ / ρg)^⅓。局部
                    kL = (2/√π)·√D_O₂·(ε/ν)^¼，a = 6·ε_g/d
                  6. 溶氧：C = m + C′，m 由全罐氧平衡给出，C′ 在流场上松弛；耗氧按 Monod 饱和；进气 O₂ 倍率由“探头处 DO = 设定值”反解（模拟 DO 串级控制）。局部 C* 计入静压与各类气泡的平推流有效 O₂ 分数。
                  7. 验证：Poiseuille 解析解（平面 0.0%、轴对称 1.5%）、能量守恒、对称性、混合终态、DO 闭环与气泡终端速度见 tests/cfd.test.js。

                  计算链

                  1. 几何：V = (π/4)T²(H − h_d) + V_head。2:1 椭圆封头 h_d = T/4、V_head = πT³/24；碟形封头 h_d ≈ 0.169T、V_head ≈ 0.0809T³近似；平底 h_d = 0。由 V 与 H/T 反算 T。
                  2. 功率：逐级叠加
                    P₀ = Σ Np_i·ρ·N³·D⁵ ·(间距 < D 时上层 ×0.8)
                    通气后 Fl = Q/(ND³)，Fl<0.035 时 Pg/P₀ = 1 − 1.26Fl，否则 0.62 − 1.85Fl。待实测校准
                  3. 双分布器 kLa：
                    kLa = K·(Pg/V)^α·(Σ w_i·vs_i)^β·f_介质·1.024^(T−20) ， w_i = f_i^(1/β)
                    单分布器时退化为 K(Pg/V)^α·vs^β·f。Van’t Riet 聚并体系 K=0.026、α=0.4、β=0.5。各分布器对传质的贡献份额 s_i = w_i·vs_i / Σ。近似
                  4. 溶氧：Benson–Krause 饱和浓度 × 盐析系数 × 平均绝压 × O₂ 分数/0.2095；C*_eff = Σ s_i·C*_i，C_L = DO% × 罐顶压力下的空气饱和值。
                    OTR = kLa(C*_eff − C_L) ， OUR = qO₂·VCD
                  5. pCO₂（稳态，气相平推流）：
                    pCO₂ = CER·V·P̄ / Σ G_i(1 − e^(−NTU_i)) ， NTU_i = kLa_CO₂,i·V·H_CO₂·P̄ / G_i
                    CER = RQ·OUR，kLa_CO₂ = 0.89·kLa_O₂·s_i，G_i 为标准摩尔气量，H_CO₂ 按 van’t Hoff 校正到培养温度。小气泡 NTU 大、很快饱和，CO₂ 去除基本由通气量决定，这与 BMS 模型的结论一致。未计液面曲面换气和加碱带入的碳酸氢盐。待实测校准
                  6. 出口气速：GEV = Q_实际 / (n_孔·πd²/4)，Q 按罐底压力和培养温度折算。
                  7. 剪切：ε_max = φ·Pg/V，φ 默认 Rushton 100、斜叶 60、翼型 40（叶轮区局部能耗可比平均高两个数量级）。Kolmogorov η = (ν³/ε)^¼。待实测校准
                  8. 混合与循环：θ₉₅ = 5.9·T^(2/3)·ε^(−1/3)·(D/T)^(−1/3)·max(1, H/T)^2.43；循环时间 t_c = V/(Σ N_Q·N·D³)。待实测校准
