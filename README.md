# 生物反应器 kLa 设计台 (v3.5)

单文件网页工具：生物反应器体积传质系数 **kLa** 设计、校核与放大估算。

- **在线地址**：https://liangxi0827-design.github.io/kla-design-platform/
- **源文件**：`kla_design_platform_v3.5.html`（与 `index.html` 内容完全一致）
- **技术栈**：原生 HTML / CSS / JavaScript，Three.js r128（CDN），Google Fonts，无需构建

## 本地打开

直接双击 `index.html` 即可在浏览器打开（无需服务器、无需安装依赖）。

## 部署

托管在 GitHub Pages，来源为 `main` 分支根目录。

## 说明

页面内含参数计算、三维反应器视图、曲线/设计空间、放大与厂商资料等内容，所有计算在浏览器本地完成，不上传任何数据。
