# 生物反应器 kLa 设计台

细胞培养搅拌罐的工程决策支持工具，单个 HTML 文件，浏览器直接打开即可使用。

## 功能

- **三维反应器**：一次性袋与不锈钢罐（夹套、保温、机封、喷淋球、阀组、平台），剖切、流型、CIP / SIP / 收获状态，部件编号引线。
- **工程计算**：功率、kLa（双分布器）、气相氧平衡下的 OTR、OUR、稳态 pCO₂、出口气速、局部能耗、混合时间。
- **设计判据**：满足 / 不满足 / 证据不足三态，每项标注证据等级与限值来源。
- **厂商与大药企构型预设**：Xcellerex XDR-2000、Biostat STR 2000、HyPerforma 2000 L、3000 / 12,500 / 20,000 L 不锈钢（示意）。
- **叶轮选型**：9 种叶轮三维展示，按工艺推荐，同等 Pg/V 下方案对比。
- **设计空间、放大 / 场地转移对比、应用场景**。
- **实测校准与优化**：导入实测 kLa 拟合（含留一交叉验证），过程数据校准，约束内多目标优化、Pareto 前沿、DO 串级分段建议。
- **CFD 流场仿真（降阶）**：过轴纵截面格子 Boltzmann（D2Q9 TRT）+ 混合长湍流闭合，叶轮推力换算速度；输出速度 / 流线、能量耗散率 ε、Kolmogorov 尺度、气含率与气泡轨迹（Hinze 破碎）、局部 kLa（Higbie + Kolmogorov 接触时间）、DO 闭环下的溶氧分布、示踪剂混合 t95；CFD 判据检查、A 厂 / B 厂对比，并可叠加到三维剖面。计算在 Web Worker 后台运行。
- **批次动态模拟（演示参数）**：CHO 补料分批质量衡算，与 DO / CO₂ 串级控制耦合；导入实测批次识别参数，训练批 / 验证批分离；A 厂 / B 厂对比。

## 使用

- 在线：仓库启用 GitHub Pages 后访问 `https://<用户名>.github.io/<仓库名>/`。
- 本地：直接用浏览器打开 `index.html`。三维图需要联网加载 Three.js（cdnjs、jsDelivr）；断网时计算功能照常。

## 测试

```bash
npm install
npx playwright install chromium
npm test
```

- `tests/engine.test.js`：计算引擎 16 项参考算例（溶解度、体积闭合、功率、关联式复现、标况 / 工况换算、氧平衡、CO₂ 物料平衡、孔速、三态判据等）。
- `tests/sim.test.js`：动态模拟 7 项（死亡衰减解析解、体积上限、DO 维持与跌落、合成数据参数回收等）。
- `tests/cfd.test.js`：CFD 14 项（Poiseuille 解析解、能量守恒、对称性、泵送数、混合时间量级、混合终态、DO 闭环、气含率一致性、Kolmogorov 尺度、气泡终端速度）。

推送到 `main` 时，GitHub Actions 先跑测试，通过后发布到 GitHub Pages。

## 重要说明

- 默认 kLa 关联式、细胞动力学参数、部分厂商参数为文献值、反推值或演示值，页面中已逐项标注。
- 未经本厂实测 kLa、批次数据校准与独立验证，结果仅供方案比选，不能直接用于确定商业生产工艺参数。
- 本工具不是经验证的 GMP 计算机化系统；若用于受监管流程，需按预期用途另行评估。
